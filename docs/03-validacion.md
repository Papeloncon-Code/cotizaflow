# CotizaFlow — plan de validación

## Pregunta central
¿Existe un segmento de pequeñas empresas venezolanas en el que el seguimiento manual de cotizaciones genere un costo repetido y no quede resuelto por las herramientas actuales?

## Investigación secundaria
- Revisar 30 vacantes actuales del segmento; guardar fecha, empresa, URL y tareas repetitivas observadas.
- Comparar 5–8 alternativas: CRM, ERP, bandejas de WhatsApp y automatización a medida.
- Distinguir páginas del proveedor, testimonios de clientes y evaluaciones independientes.
- No inferir cuota de mercado a partir de reseñas o de una función anunciada.

## Muestra exploratoria
Construir una lista de 30 empresas de un mismo segmento a partir de directorios, páginas públicas y vacantes. Contactar individualmente a responsables de ventas, administración u operaciones. Meta inicial: 8–12 entrevistas. La muestra no será estadísticamente representativa.

## Preguntas
1. Cuéntame la última cotización que enviaste, desde la solicitud hasta el desenlace.
2. ¿Dónde registras importe, estado, responsable y próximo contacto?
3. ¿Cómo sabes qué cotizaciones requieren seguimiento hoy?
4. ¿Qué pasó la última vez que una cotización se atendió tarde o quedó olvidada?
5. ¿Cuántas cotizaciones gestionas por semana y cuánto tiempo dedicas a revisarlas?
6. ¿Qué herramientas utilizas y qué parte del proceso queda fuera de ellas?
7. ¿Quién decide cambiar el proceso y qué tendría que demostrar una solución?
8. ¿Podrías mostrar un ejemplo anonimizado o probar un flujo con datos ficticios?

Evitar preguntar primero si la persona quiere IA. Pedir ejemplos de conducta pasada y, si es posible, observar el proceso real con permiso.

## Señales para avanzar
- Varias entrevistas independientes describen el mismo problema.
- Hay ejemplos recientes y una consecuencia cuantificable.
- Se confirma una limitación concreta de la herramienta actual.
- Una empresa acepta un piloto y define métricas.
- El beneficio potencial supera costos, riesgos y mantenimiento.

## Señales para detenerse o cambiar
- El problema es raro o de bajo impacto.
- El CRM existente ya lo resuelve.
- No se puede acceder legítimamente a datos necesarios.
- El caso depende de promesas no verificables de ventas recuperadas.
- Las integraciones o sus costos impiden un flujo fiable.
